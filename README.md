# 五十音マインスイーパー

五十音表を使った2人対戦のワード推理ゲームです。

お題の答えに含まれる文字が五十音表上の「地雷」になります。プレイヤーは交互に「回答 → 1文字開ける」を行い、先に正解した方が勝ちです。地雷を開いたプレイヤーは、次の自分のターンだけ回答権を失います。

## 文字ルール

- 小文字は区別しない（`っ → つ`, `ゃ → や` など）
- 濁音・半濁音は区別しない（`が → か`, `ば/ぱ → は` など）
- 長音 `ー` は独立した文字として扱う
- 同じ文字の重複を許可する
- 盤面は一般的な縦書き五十音表で、`ー` は `ん` の下に置く
- 同カテゴリ・同文字数で正規化後の文字カウントが衝突する単語は、同じ問題の `answers[]` にまとめて複数正解にできる

## 問題データ

`src/data/questions.ts` の1問は次の形です。

```ts
{
  id: "sport-table-tennis",
  category: "スポーツ",
  answers: ["たっきゅう"]
}
```

表示するお題の文字数は、答えをゲーム用ルールで正規化したあと自動計算します。
