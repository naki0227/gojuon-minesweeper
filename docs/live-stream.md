# 参加型ライブ配信（コメントでみんなで解く）

視聴者がコメントした文字でマスが開き、答えをコメントで当てる配信。
いまはローカルで試せる段階で、YouTube のチャット読み込みと配信の自動開始は次の段階で足す。

## 遊び方（画面に出ている説明と同じ）

- コメントに **1文字**（例：`か`、カタカナでも可）→ そのマスが開く
- 答えがわかったら **そのままコメント**（`答え：○○` でも可）
- 正解するとポイント。開いたマスが少ないほど高い（10点〜1点）
- 誰も当てられないまま盤面が開ききると、45秒後に答えを出して次の問題へ

## Windows で動かす

1. Node.js（LTS）を入れて、このリポジトリで `npm install`
2. `npm run live`
3. ブラウザで <http://127.0.0.1:4173/dev> を開く。名前と文字を打って「送る」で試せる
4. 配信用の画面は <http://127.0.0.1:4173/>（1280×720）。OBS の「ブラウザ」ソースにこの URL を入れる。
   音声を流すなら、ソースの「OBSで音声を制御する」にチェック

サーバーはこの PC からしか開けない（127.0.0.1 だけで待ち受け）。

## 実況（Claude Code）

正解が出たときのひとことは、この PC でログインしている Claude Code（`claude -p`）が書く。
Claude Code が入っていない、または失敗したときは、決まった文に切り替わる。

- コメントの名前や文字は「データ」として渡し、ツールも MCP も無し、空のフォルダで動かす
- 返ってきた文は 1 行・50 文字までに切り、URL っぽいものは捨てる
- 使うのはサブスクの利用枠。正解のときだけ呼ぶので 1 問 1 回
- 環境変数：`LIVE_HOST=off`（Claude を使わない）、`LIVE_HOST_MODEL`（既定 `haiku`）、`LIVE_CLAUDE_BIN`（`claude` の場所）

## 読み上げ（VOICEVOX）

[VOICEVOX](https://voicevox.hiroshiba.jp/) を起動しておくと、実況の文を読み上げる。起動していなければ文字だけ。

- 既定の声は話者 ID `3`（ずんだもん）。`VOICEVOX_SPEAKER` で変えられる
- **配信の概要欄にクレジットが必要**（例：`VOICEVOX:ずんだもん`）。キャラクターごとの利用規約も確認する
